# Lifeline Daily — Stage 1 Decision Register v1.2

Every decision an agent would otherwise have to ask about is listed with a **selected default**. Revised 22 Oct 2026 after an independent review (`CODEX_REVIEW_BRIEF.md`): DEC-01…28 amended where noted, DEC-31…38 added. 23 Oct 2026: DEC-12 amended (no footer link), DEC-39…43 added for the category tidy-up and footer. The loop proceeds on the default. To override, change the `Selected` cell and bump `decided_on`; the registry JSON mirrors this table and CI fails if they disagree (`SCH-01`). Decisions marked **HG** must be ratified by a human at the named gate but do not block work before that gate.

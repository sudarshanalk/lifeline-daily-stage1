How our tools work

Named methods

Every number traces to a published guideline or validated model. Each tool names its method, version and limits.

Nothing stored unless you ask

Public tools run in your browser. Members can choose to save results, and can delete them at any time.

Not a diagnosis

Screening aids only. A clinician and, where relevant, a blood test are needed to diagnose anything. When to seek urgent care
